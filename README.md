# 🗑️ TKJ Dumps

"Gabut itu bukan dosa, tapi seni. Tapi kalau malas baca tutorial, itu kriminal."

Repository ini berisi kumpulan arsip proyek massal berbasis Google Colab (`.ipynb`) yang dibangun menggunakan metode **Hibrida (Otak Developer + Kecerdasan Buatan)**. Proyek ini dikerjakan secara gratis demi solidaritas untuk membantu teman-teman bertahan hidup dari tugas produk TKJ sekolah.

## 📌 Catatan & Disclaimer Utama
* **100% Gratis:** Semua kode di sini dikerjakan tanpa biaya sepeser pun. Hal ini sengaja dilakukan agar developer terbebas dari beban moral atau tuduhan scamming jika pengguna gagal paham.
* **Tanggung Jawab Pengguna:** Konsep produk, visi, passion, hingga dokumentasi cara *running* program sebenarnya sudah diserahterimakan dengan jelas. Kegagalan eksekusi akibat minimnya tingkat literasi atau kebiasaan malas membaca di luar tanggung jawab developer.
* **Riwayat Isolasi:** File `Projek_Jipa.ipynb` sempat diasingkan ke branch khusus (`Ngedumel`) karena user bersangkutan hobi mengeluh sebelum membaca dokumentasi dasar, sebelum akhirnya di-merge kembali untuk melengkapi arsip.

## 🏁 Panduan Singkat untuk Pengguna Minim Literasi
Daripada tersesat selama 5 menit di depan BIOS atau bingung menggunakan Python versi mutakhir yang belum stabil, berikut aturan emas sebelum menjalankan proyek di komputer laboratorium:

1. **Gunakan Versi Stabil:** Google Colab berjalan optimal di lingkungan produksi yang stabil (Python 3.12). Jangan fomo menggunakan versi Beta yang ekosistem library-nya (TensorFlow, CUDA, XPixel) belum siap mendukung.
2. **Aktifkan Virtualisasi di BIOS:** Jika Oracle VirtualBox Anda crash saat dijalankan, solusinya bukan bertanya ke AI secara bertele-tele, melainkan:
   * **Spam F2** saat booting untuk masuk ke menu BIOS.
   * Masuk ke tab **Advanced / CPU Configuration**.
   * Ubah status **Intel Virtualization Technology (VT-x)** atau **SVM Mode (AMD)** menjadi **Enabled**.
   * Save, reset, dan reboot.
